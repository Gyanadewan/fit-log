# FitLog — Workout Library

FitLog is a modern workout library application where users can explore different workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

## Technologies Used

- Next.js
- JavaScript
- React
- DaisyUI
- Tailwind CSS
- Context API
- React Icons
- React Toastify
- Vercel
## Features

- Browse all available workouts from the workout library
- View detailed information about each workout
- Add workouts to Today's Plan
- Save workouts for later
- View and manage planned workouts
- Mark workouts as completed
- Remove workouts from Today's Plan
- Sort workouts by duration, calories, and rating
- Dynamic Plan and Saved workout counters
- Toast notifications for user actions
- Fully responsive design for mobile, tablet, and desktop
